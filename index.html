2026-09 AI & Systems
Latest Release

Maki: Remote Control & Web UI for Native AI Coding Agents

AI coding assistants shouldn't require bloated, memory-hungry Electron wrappers that trap your codebase in closed clouds. Maki is a native, lightning-fast Rust-based AI agent extendable via Neovim-style Lua plugins and the Agent Client Protocol (ACP) for modern editors like Zed.

We expanded Maki with full remote control capabilities and a dedicated Web UI to monitor, prompt, and manage autonomous coding sessions from any browser on the local network or Tailnet. We eliminated latent race conditions in async control tunnels so commands execute synchronously without synthetic pauses, hooked dynamic provider scripts into ~/.config/maki/providers/, and optimized local model routing.

"Why rent a closed SaaS agent when you can run a native Rust engine directly on your hardware, hack it with Lua, and orchestrate it remotely from a clean Web UI?" — William Mantly
curl -fsSL https://maki.sh/install.sh | sh

2026-07 Infrastructure
Unified Milestone

The Sovereign Stack: Theta Suite v1.5.0 & Complete UI Unification

Setting up enterprise-grade identity, access, and secrets in a home lab or small enterprise used to mean wrestling with Okta bills or Keycloak's overwhelming resource footprint. Theta Suite (formerly theta-env) bundles an OIDC/LDAP identity provider, an OIDC-aware reverse proxy, an inventory-driven SSH jump host, and Linux host enrollment into a single ./setup.sh Docker Compose stack.

In v1.5.0, we completed full UI unification across all three core apps (Proxy v1.4.0, Theta Directory v1.5.0, and Jump Host v1.3.0). Every app now shares a byte-identical shell, unified client-side group gating, cached OIDC auth promises, and automated inventory graphing for Proxmox VMs, UniFi clients, and Docker containers—all reading from a shared OpenBao secrets store.

"Enterprise SSO without the enterprise. Keycloak and Authentik make you bring your own directory; Theta Suite ships one out of the box."
git clone https://github.com/theta42/theta-suite.git && cd theta-suite && ./setup.sh

2025–2026 Community & Lore
Community Preserved

The Rebirth of CoreJourney: Rescuing 5 Years of History (#SaveCJ)

In February 2025, after 5 years of continuous hardcore survival, the original creator of CoreJourney announced the server would permanently shut down on its 5th anniversary due to lack of time and hosting funds. For thousands of players who had built monuments, fought clan wars, and endured real death bans, a digital universe was about to vanish.

William (known in-game as tux4242 / wmantly / useless666), a 5-year veteran player, posted the #SaveCJ pledge to take the torch. The transfer was agreed upon: 1.5 TB of raw Minecraft world history was transferred over a 10GbE fiber link directly to enterprise HPE DL380 servers in his homelab.

Through the community "CDD" (CoreJourney Disk Drive) fundraiser, players pooled together to buy Crucial MX500 SSDs for redundant ZFS mirrors. William modernized the stack through versions 1.20, 1.21.4, 1.21.10, and 26.1.2 ("Spring to Life"). He engineered a custom SQLite WAL live statistics platform (corejourney.org) tracking PvP kills, rivalries, death bans, and player lifespans, alongside a community lore wiki (wiki.corejourney.org).

"Technically, CJ is now run and operated by Theta 42? But I'm Theta 42 and Theta 42 is me... We don't do pay-to-win. You donate $5 and get a Golden Dandelion or a copper pickaxe; 100% of the funds keep the hardware running and pay the electric bill." — #SaveCJ Announcement

2025-01 Infrastructure
Core Engine

The Proxy: Dynamic Zero-Reload Ingress with Native Directory SSO

Most reverse proxies treat authentication as an afterthought or force you into clunky third-party middleware plugins with static configuration files. We built Theta Proxy to put any backend service behind single sign-on with zero reload downtime.

Built on OpenResty with Lua-based edge routing and a Node.js management API, it interfaces with Redis via our custom model-redis ORM. It automatically handles Let's Encrypt wildcard certificates via DNS-01 challenges (supporting Porkbun, Cloudflare, DigitalOcean, and DuckDNS). Crucially, it speaks both OIDC and OpenLDAP directly, allowing access decisions to be evaluated against real user directory groups in real time.

"Per-host rate limiting, response caching, HSTS, round-robin load balancing, and self-service API tokens for automation—all without restarting Nginx."
git clone https://github.com/theta42/proxy.git && cd proxy && sudo ./ops/install.sh

SimpleWorkJS: Stripping the Bloat from Modern Node.js

Why do modern web application backends require 50 configuration files, complex decorator DSLs, and thousands of transitive dependencies? SimpleWorkJS is a minimalist toolkit designed for developers who want simplicity and speed:

@simpleworkjs/conf offers hierarchical config management in one require: drop a conf/ directory with base.js, per-environment overrides, and a gitignored secrets.js, deep-merging by NODE_ENV with one dependency. Paired with @simpleworkjs/orm-identity, @simpleworkjs/backend, and @simpleworkjs/bao-conf (Vault KV-v2 integration), it powers fast, robust distributed apps.

npm install @simpleworkjs/conf @simpleworkjs/backend @simpleworkjs/orm-identity

Codeland: Self-Hosted Serverless Containers on Frugal Hardware

Long before modern browser-based execution platforms like Replit were properly established, we engineered Codeland: a self-hosted serverless code execution platform supporting 24 programming languages inside genuine isolated Linux containers (LXC).

The codeland-ecosystem featured a sophisticated control plane: pre-warmed container pools for instant sub-second cold starts, interactive WebSocket terminals, auto-scaling worker nodes, and instant public URLs—all running smoothly on a frugal $40/month infrastructure footprint.

"Real Linux containers, instant terminal multiplexing, and auto-scaling runners. A testament to architecting systems cleanly instead of burning venture capital."

2016-04 Frameworks & Tools
Open Source Classic

jq-repeat: Reactive DOM Lists Without Monolithic Frameworks

Angular 1.x introduced developers to the magic of ng-repeat, but importing an entire monolithic framework just to synchronize an array of items with the DOM was unnecessary bloat.

We built jq-repeat to bring reactive, declarative list rendering to jQuery and vanilla JS. It automatically synchronizes the DOM when arrays are mutated via push, pop, or splice, while providing granular lifecycle animation hooks (__put, __take, __putUpdate). It proved that reactive interfaces don't require 300KB bundle sizes.

npm install jq-repeat

Guiding Principles

Why We Build In The Open

Digital Sovereignty

You should own the machines that store your data, authenticate your identity, and run your models. Rent-seeking cloud subscriptions and black-box SaaS APIs compromise privacy, security, and long-term autonomy.

Pragmatic Architecture

Software should be lean, battle-tested, and transparent. We avoid configuration ceremony, bloated dependencies, and speculative complexity in favor of straightforward code that stays running for years.

Community Stewardship

Whether preserving an unmaintained open-source library or rescuing a 5-year gaming community from shutdown, code is about people. We build with strict integrity, zero pay-to-win tricks, and complete transparency.

Back Independent Software

Keep The Hardware Powered & Code Free.

Theta42's community tools, open-source repositories, and public servers (like CoreJourney) are self-hosted on physical enterprise servers (HPE DL380s with 10GbE networking and Crucial MX500 ZFS mirror storage arrays).

We don't take venture capital, we don't sell user data, and we don't do pay-to-win. 100% of community contributions go directly toward:

  • Server electricity, cooling, and homelab hosting power
  • High-end SSD replacements and ZFS storage drives
  • Domain registrations and DNS infrastructure
  • Dedicated CI/CD build runners and continuous development
